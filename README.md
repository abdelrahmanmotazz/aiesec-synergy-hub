An executive-grade, interactive operations and strategy platform designed to establish a unified operational ecosystem between **B2C/Marketing** and the Outgoing Exchange functions (**oGV & oGT**). 

By synchronizing market positioning, cross-funnel lead routing, joint on-campus activations, and stringent accountability SLAs, this platform maximizes lead capture, eliminates drop-offs, and drives Customer Lifetime Value (CLV).

---

## 🌟 Key Functional Modules

### 1. 🔄 Interactive Strategic Synergy Framework
- **Full-Funnel Lifecycle Map**: Visual interactive node map connecting *Unified B2C Lead Gen* &rarr; *oGV / oGT Match* &rarr; *Bi-directional Cross-Routing* &rarr; *Approvals* &rarr; *Returned EP Network*.
- **Stage Deep-Dive Drawer**: Click any stage to access key performance thresholds, operational checklists, and SLA accountability rules.

### 2. 🧭 Smart Router & First-Contact Pitch Generator
- **Candidate Profiler**: Calibrates academic year, motivation, timeline availability, experience level, and English readiness.
- **Dynamic Fit Scoring**: Instant algorithm computing oGV Fit % vs oGT Fit % with strategic justification.
- **1-Click Communication Generator**: Ready-to-send WhatsApp and formal Email first-touch pitches.
- **Dispatch to Live CRM**: Dispatches matched candidates directly into the CRM with confetti milestone celebration.

### 3. 👥 Market Segmentation & Persona Alignment
- **Comparative Persona Matrix**: Side-by-side analysis across 6 core dimensions (Audience, Motivation, Duration, Messaging, Channels, Barriers).
- **Objection Crusher & Playbook**: Battle-tested counter-pitches for tough objections ("need a job immediately", "no commercial work experience", "parent skepticism", "financial doubts").

### 4. ⏱️ Cross-Funnel SLA & Live CRM Hub
- **24-Hour & 12-Hour SLA Timers**: Live countdown trackers ensuring 100% first-contact and rapid cross-transfer compliance.
- **Down-Funnel Nurturing ($oGT \rightarrow oGV$)**: Re-routes candidates lacking corporate history to 6-week SDG volunteer projects to build leadership grit first.
- **Up-Funnel Progression ($oGV \rightarrow oGT$)**: Automatically retargets graduating oGV returnees for corporate talent placements.
- **Pipeline Actions**: Stage advancement, instant cross-routing modal, search, filter, and 1-click **Export to CSV**.

### 5. 📅 Joint Operational Cadence & Touchpoints
- **4-Stage Academic Semester Roadmap**: Strategy kick-off, integrated ad campaigns, Global Opp Fairs, and post-exchange upselling.
- **Cadence Blueprints**: Weekly Alignment, Bi-Weekly Sourcing Sprint, Monthly Sales Clinic, and Quarterly Strategic Shift with agendas and deliverables.
- **Live Action Items Tracker**: Assign tasks to B2C, oGV, oGT, or Joint teams with completion toggles.

### 6. 🎪 Integrated Marketing & Activation Playbook
- **Global Opportunities Fair Blueprint**: Floorplan specs for Zone A (oGV Impact Hub), Zone B (oGT Career Lounge), and Zone C (Synergy Fast-Track Desk).
- **Interactive SDG Wheel Game**: Spin the on-campus UN SDG wheel to reveal paired volunteer projects and corporate internships.
- **"From Volunteer to Professional" Series**: Script formulas and real case studies converting student skepticism into high engagement.
- **Bi-Weekly Opportunity Spotlight (3 + 3 Format)**: Paired 3 oGV impact projects + 3 oGT paid internships.

### 7. 📈 Executive Performance Analytics & What-If Simulator
- **Core Synergy KPIs**:
  $$\text{Synergy Conversion Rate} = \left( \frac{\text{Total Approvals (oGV + oGT)}}{\text{Total Leads Generated by B2C}} \right) \times 100$$
  - Cross-Routing Recovery Yield %
  - 24h Contact SLA Speed Compliance
  - Combined Cost Per Approval (CPA)
- **What-If Scenario Simulator**: Sliders for B2C Budget, Lead Volume, Cross-Routing Efficiency, and SLA Speed dynamically projecting approvals and ROI.

### 8. 🎨 Aesthetic Theme Suite
- **AIESEC Signature**: Classic Royal Blue & crisp frosted glass.
- **Global Volunteer (oGV)**: Coral & Sunset warmth.
- **Global Talent (oGT)**: Cyber Teal & Emerald deep navy.
- **Synergy Holographic**: Futuristic purple-cyan gradients.
- **Executive Frost Light**: High-contrast, clean daylight UI.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/abdelrahmanmotazz/aiesec-synergy-hub.git

# Navigate to project folder
cd aiesec-synergy-hub

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build
```
